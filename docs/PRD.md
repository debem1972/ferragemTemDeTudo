# PRD --- temDeTudo Ferragem (E-commerce)

## 1. Visão do Produto

**temDeTudo Ferragem** é um e-commerce fictício focado na venda de: -
Ferramentas (manuais e elétricas) - Materiais elétricos e hidráulicos -
Ferragens em geral - Equipamentos de energia solar (on-grid e off-grid)

O objetivo é demonstrar habilidades fullstack com foco em: - CRUD
completo - Autenticação de usuários - Catálogo dinâmico - Carrinho e
simulação de compra

------------------------------------------------------------------------

## 2. Objetivo do Projeto

Criar um sistema que demonstre: - Organização de código - Integração
frontend + backend - Consumo de API REST - Boas práticas (MVC) -
Estrutura realista de e-commerce

------------------------------------------------------------------------

## 3. Público-alvo

-   Avaliadores técnicos (recrutadores)

------------------------------------------------------------------------

## 4. Funcionalidades Principais

### Catálogo

-   Listagem de produtos
-   Imagem, descrição, preço, estoque
-   Filtros por categoria
-   Busca por nome

### Ofertas

-   Página detalhada das ofertas
-   Imagem, descrição, preço real, preço promo
-   Filtros por categoria
-   Busca por nome

### Destaques

-   Produtos em destaque na loja
-   Lançamentos no mercado

### Carrinho

-   Adicionar/remover itens
-   Alterar quantidade
-   Calcular total

### Usuário

-   Cadastro
-   Login/logout
-   Área do usuário

### Checkout (simulado)

-   Resumo do pedido
-   Finalização fictícia

### Admin

-   CRUD de produtos
-   Upload de imagens
-   Controle de estoque
